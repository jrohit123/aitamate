01 Overview

The ProValuate API lets you automate every stage of the candidate assessment lifecycle — from parsing job descriptions and scoring resumes, to conducting dynamic AI-driven interviews and generating detailed reports.

💡
What you can build: Embed resume screening inside your existing ATS, trigger automatic interviews on candidate application, pull assessment scores into your HRMS dashboard, or build custom hiring workflows with full programmatic control.

API Architecture

All endpoints are RESTful and return JSON responses. File uploads use multipart/form-data. All other requests use application/json.

02 Authentication

The ProValuate API uses two identifiers to authenticate and scope every request: your Company ID and User ID. These are passed in the request body or as query parameters — never in headers.

  • 1
    Log in to your ProValuate dashboard
    Navigate to Settings → API Access to retrieve your Company ID and User ID.
  • 2
    Include credentials on every request
    Attach company_id and user_id in the request body or as query params. All data is scoped to your company.
  • 3
    Secure your credentials
    Never expose credentials client-side. Always make API calls from your server or secure backend environment.
Example — Credential Usage 
# Every request should include these identifiers
{
  "company_id": "bea223c9-94c0-483e-bc36-cd11826f32f5",
  "user_id":    "336e4422-d872-4f58-810e-4eb59da73206"
}

04 Upload Resume

Upload a candidate's resume PDF to ProValuate storage. Returns a hosted file URL used in subsequent analysis calls.

POST /cv/upload Upload a resume file

Request — multipart/form-data

ParameterTypeRequiredDescription
fileFilerequiredPDF file of the candidate's resume
company_idstringrequiredYour company UUID
user_idstringrequiredUser performing the upload
jd_idstringrequiredJob description UUID to assess against
criteria_idstringoptionalScoring criteria UUID
candidate_namestringoptionalCandidate's display name

The interview API lets you programmatically create, conduct, and retrieve AI-driven candidate interviews. Supports both functional and behavioral interview types.

POST /api/create-interview Initialize a new interview session
ParameterTypeRequiredDescription
candidate_namestringrequiredFull name of the candidate
positionstringrequiredRole being interviewed for
candidate_emailstringrequiredCandidate's email address
company_idstringrequiredYour company UUID
interview_typestringoptionalfunctional or behavioral
custom_instructionsstringoptionalAdditional interviewer context
Response — 200 OK
{
  "interview_id": "3e754fc9-1fbd-4c05-acee-58db8549eabc",
  "status":       "pending",
  "interview_url": "https://app.provaluate.com/interview/3e754fc9"
}
POST /api/generate-question Generate the next interview question

Generates a contextual follow-up question based on the interview history and configured parameters. Pass interview_id in the body.

POST /api/submit-answer Submit a candidate's answer for scoring
ParameterTypeRequiredDescription
interview_idstringrequiredThe active interview session ID
question_idstringrequiredThe question being answered
transcriptstringrequiredTranscribed text of the answer
audio_urlstringoptionalHosted audio recording URL
written_answerstringoptionalWritten portion of the answer

08 Error Codes

All errors return a JSON body with a status of "error" and a descriptive message field.

CodeMeaningCommon Cause
200OKRequest succeeded
400Bad RequestMissing required parameters or malformed JSON
401UnauthorizedInvalid or missing company_id / user_id
404Not FoundResource (JD, resume, interview) does not exist
500Server ErrorInternal processing failure — contact support
Error Response Shape
{
  "status":  "error",
  "message": "Missing required parameter: jd_id"

10 Webhooks

ProValuate can push real-time notifications to your endpoint when key events occur — such as when a resume analysis completes or a candidate finishes an interview.

🔔
Webhook support is available on Pro and Enterprise plans. Configure webhook URLs from Settings → Integrations → Webhooks in your dashboard. Contact sales@aitamate.com to enable.

Supported Events

EventTrigger
assessment.completedResume analysis and scoring has finished
interview.completedCandidate has completed all interview questions
interview.startedCandidate has begun the interview session
report.readyFull report with speech analysis is available
Webhook Payload Example
{
  "event":        "assessment.completed",
  "timestamp":    "2026-03-06T10:30:00Z",
  "company_id":   "bea223c9-94c0-483e-bc36-cd11826f32f5",
  "data": {
    "assessment_id":   "761ecbd0-f2aa-4df1-ad22-c95419065993",
    "candidate_name":  "Kartik Batchu",
    "final_score":     6.39,
    "recommendation":  "To be interviewed"
  }
}
